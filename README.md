# MyAvoidSphereGame

하늘에서 떨어지는 공을 피하는 Unity 프로토타입.
Claude Code + Unity MCP로 AI와 같이 만들어 봤다.

![플레이 화면](docs/images/03-sphere-falling.png)

## 게임

- WASD로 캡슐 이동
- 3초마다 공중에서 공이 떨어짐
- 맞으면 Game Over, 좌상단 생존시간이 멈춤

## 실행

Unity 6000.3.26f1 (URP)로 열고 `Assets/Scenes/SampleScene` 실행.
