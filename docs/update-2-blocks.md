# 개선 2차: 블록 쌓고 올라가기

![블록 낙하](images/07-block-falling.png)

## 변경 내용

공을 피하기만 하던 게임을, 떨어지는 블록을 피하면서 쌓인 블록을 딛고 더 높이 올라가는 게임으로 바꿨습니다.

- 떨어지는 장애물을 공에서 테트리미노 블록(7종, 높이 1칸)으로 바꿨습니다.
- 10×10 필드를 1×1 칸으로 나누고, 블록이 칸에 딱 맞게 떨어지도록 했습니다.
- 떨어진 블록은 사라지지 않고 쌓여서 지형이 됩니다.
- 점수는 지금 서 있는 높이(`Height`)로 바꾸고, 생존시간은 작게 남겼습니다.
- 점프, 가속·감속, 카메라 따라가기를 넣었습니다.
- 회전하던 Cube와 장식 Cube는 칸에 맞지 않아서 모두 지웠습니다.
- 블록 간격을 3초에서 시작해 90초 동안 1.5초까지 점점 줄였습니다.

## 변경 이유

기본 게임은 피하는 것 말고는 할 일이 없었고, 떨어진 공은 사라져서 판이 진행돼도 달라지는 게 없었습니다.
그래서 "블록을 피하면서, 쌓인 블록을 딛고 더 높이 올라가는 플레이"를 목표로 잡았습니다. 떨어진 것이 남아 발판이 되려면 위치가 딱 맞아야 해서, 테트리스처럼 칸에 맞춰 떨어지는 블록으로 정했습니다.
목표가 "오래 버티기"에서 "높이 올라가기"로 바뀌었기 때문에, 점수도 높이로 바꿨습니다.

## 플레이에서 달라진 점

- 블록이 떨어질 때마다 지형이 바뀌어서, 판마다 올라가는 길이 다릅니다.
- 블록을 피하는 것과 블록 위로 올라가는 것이 같이 있어서, 무작정 도망만 다닐 수 없습니다.
- 떨어질 자리가 미리 보여서, 맞았을 때 "못 피할 거였다"는 느낌이 줄었습니다.
- 높이가 올라가면 카메라도 같이 올라가서 화면 밖으로 나가지 않습니다.
- Game Over가 되면 블록이 전부 빙글빙글 돌아서, 죽는 순간이 조금 덜 허무합니다.

## 블록

- ProBuilder로 1칸짜리 큐브 4개를 합쳐 7종 프리팹을 만들었고, 스포너가 `Instantiate`합니다 (`Assets/Prefabs/Blocks`).
- 눕힌 상태로 떨어지고, 90도 단위로 랜덤 회전합니다.
- 보이는 큐브는 0.96 크기라 칸 사이에 살짝 틈이 보입니다. 충돌 범위는 정확히 1×1입니다.
- 낙하는 물리 중력 대신 스크립트로 움직입니다. 착지할 높이를 미리 계산해 두고 거기서 멈춥니다. 물리로 떨어뜨리면 튕기거나 미끄러져서 칸이 어긋났습니다.
- 떨어지는 중인 블록에 닿으면 Game Over이고, 착지한 블록은 발판입니다.

## 낙하 알고리즘

요청한 기준은 "플레이어가 느끼기에 불합리하지 않고, 동시에 자연스럽게"였습니다.

### 불합리하지 않게

1. 블록이 생기는 순간, 떨어질 칸에 반투명 그림자와 빨간 외곽선을 띄웁니다. 그림자만으로는 잘 안 보여서 빨간 외곽선을 넣어 달라고 했습니다. 땅에 가까워질수록 빨리 깜빡입니다.
2. 블록은 생기자마자 떨어지지 않고 공중에서 0.8초 멈춰 있습니다. 표시를 보고 피할 시간입니다.
3. 플레이어를 노리는 블록이라도 상하좌우 중 한 칸은 비워 둡니다. 그 칸은 높이 차이가 1칸 이하여야 해서, 실제로 도망갈 수 있는 칸입니다.
4. 플레이어를 노리는 블록은 35% 확률이고, 두 번 연속으로 노리지는 않습니다.
5. 이미 떨어지고 있는 블록이 차지한 칸에는 새 블록을 놓지 않습니다.

### 자연스럽게

블록마다 후보 자리를 12개 뽑아 점수를 매기고, 점수가 가장 낮은 자리에 떨어뜨립니다.

| 항목 | 점수 | 이유 |
|---|---|---|
| 블록 밑에 생기는 빈 공간 | 칸당 +3 | 공중에 뜬 어색한 모양을 줄이려고 |
| 주변보다 2칸 이상 높아지는 면 | 면당 +1.5 | 점프로 못 오르는 벽을 줄이려고 |
| 노릴 때, 플레이어와의 거리 | 칸당 +4 | 가까울수록 노리는 의미가 있어서 |
| 안 노릴 때, 플레이어 바로 옆 | +8 | 노리지도 않는데 옆에 떨어져서 놀라지 않게 |
| 랜덤 | 0~2 | 매번 같은 패턴이 나오지 않게 |

테트리스처럼 가장 높은 칸에 걸려서 멈추는 방식이라 밑에 빈 공간이 생길 수 있습니다. 점수로 그런 자리를 덜 고르게 했습니다.

## 조작감

- 최고 속도 6에 가속 60, 감속 80을 줬습니다. 키를 떼면 거의 바로 서지만 뚝 끊기지는 않습니다. 공중에서는 60%만 적용됩니다.
- 점프 높이는 1.3입니다. "점프로는 한 번에 한 칸씩만" 올라갈 수 있게 해 달라고 해서, 1칸은 오르고 2칸은 못 오르는 높이로 맞췄습니다.
- 떨어질 때는 중력을 2배로 해서 붕 뜨는 느낌을 줄였습니다.
- 블록 끝에서 떨어진 직후 0.1초 동안은 점프가 됩니다 (코요테 타임).
- 착지 직전 0.15초 안에 누른 점프는 기억했다가 착지하자마자 뛰게 했습니다 (점프 버퍼).
- 블록 옆면에 붙어서 안 떨어지는 문제가 있어서 플레이어 마찰을 0으로 했습니다.
- 처음엔 캡슐 반지름이 0.5라 칸을 꽉 채워서, 옆 칸에 블록이 떨어지기만 해도 스쳐서 죽었습니다. 반지름을 0.35로 줄였습니다.
- 필드 둘레에 보이지 않는 벽을 둬서 밖으로 나갈 수 없습니다.

## Game Over 연출

Game Over가 되면 필드의 모든 블록에 `Rotator`를 붙여 제자리에서 돌게 했습니다. 기본 미션 때 만든 `Rotator`를 다시 쓴 것이고, 재밌을 것 같아서 넣었습니다.

블록 Rigidbody의 보간(Interpolate)이 켜져 있으면 `Rotator`가 돌린 각도를 Rigidbody가 덮어써서, 돌기 시작할 때 보간을 끕니다.

![Game Over 때 블록 회전](images/10-game-over-spin.png)

블록 21개 모두에 `Rotator`가 붙고, 각도가 계속 바뀌는 것까지 확인했습니다.

## 확인

MCP로는 키 입력을 넣을 수 없어서, 블록이 오래 쌓이는 모습은 플레이어 충돌을 잠시 끄고 확인했습니다.

![75초쯤 쌓인 필드](images/08-stacked-field.png)

75초 동안 블록 30개 정도가 0~4층으로 쌓였습니다. 대부분 1칸 차이라 올라갈 만한 지형이었고, 2칸 이상 벽도 가끔 생겼습니다.

![4층 위에서](images/09-climbed-height.png)

플레이어를 4층 블록 위에 올려 두면 `Height: 4`가 되고, 카메라도 그만큼 따라 올라갑니다.

- [x] 블록이 칸에 맞게 떨어지고, 착지 후 남습니다
- [x] 착지 지점에 그림자와 빨간 외곽선이 뜨고, 착지하면 사라집니다
- [x] 가만히 서 있으면 노리는 블록에 맞아 Game Over가 됩니다 (11.7초)
- [x] 높이 점수와 카메라 따라가기가 동작합니다
- [x] 점프 높이는 약 1.3으로, 1칸은 오르고 2칸은 못 오릅니다
- [x] WASD와 Space로 직접 올라가 봤습니다
