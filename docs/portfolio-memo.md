# 포트폴리오 메모

- 과제 사양 표를 그대로 Claude Code에 넘기고, 애매한 부분은 먼저 물어보게 했습니다. Cube 배치 시점이나 Game Over 후 처리 같은 결정은 제가 내렸습니다.
- Claude가 Unity MCP로 에디터에 연결해 스크립트 작성, 씬 구성, Play 테스트까지 했고, 저는 결과를 Console과 화면으로 다시 확인했습니다.
- 코드는 그대로 받지 않고 리뷰했습니다. `public` 필드는 캡슐화를 위해 `[SerializeField] private`으로 바꿨습니다.
- 추가 개선에서는 방향과 규칙은 제가 정하고, 구현과 테스트는 Claude에게 맡긴 뒤 직접 플레이하며 수치를 조정했습니다.
