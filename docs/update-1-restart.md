# 개선 1차: 재시작

## 변경 내용

Game Over가 되면 화면 가운데에 `GAME OVER / Press R to Restart` 문구를 띄우고, R키를 누르면 처음부터 다시 시작하도록 했습니다.

## 변경 이유

기본 미션 상태에서는 Game Over 이후에 할 수 있는 것이 없었습니다. 다시 하려면 에디터에서 Play를 껐다가 켜야 했고, Game Over 여부도 Console에만 찍혀서 게임 화면만 보고는 알기 어려웠습니다.
추가 도전 예시에 있던 "Game Over 후 재시작"을 먼저 하기로 했고, 2차 작업(블록 쌓기)도 이 게임 루프 위에서 테스트해야 해서 1차로 잡았습니다.

## 플레이에서 달라진 점

- 맞는 순간 화면이 어두워지면서 문구가 떠서, 죽었다는 것을 바로 알 수 있습니다.
- R 한 번이면 바로 다음 판을 할 수 있어서, 여러 판을 연달아 하기 편해졌습니다.

## 구현

- 재시작 방식은 Claude가 R키, 버튼 중에 물어봤고, R키와 안내 문구로 정했습니다.
- R키는 Game Over 상태에서만 받습니다. 플레이 중에 잘못 눌러도 초기화되지 않습니다.
- 재시작은 `SceneManager.LoadScene`으로 현재 씬을 다시 불러옵니다. 값을 하나씩 되돌리는 것보다 빠뜨리는 부분이 없습니다.

## 확인

- [x] Sphere에 맞으면 Game Over 문구가 뜹니다
- [x] 재시작하면 문구가 사라지고, 시간은 0부터, 플레이어는 처음 위치에서 시작합니다
- [x] R키를 직접 눌러서 재시작되는 것을 확인했습니다 (MCP로는 키 입력이 막혀서 직접 테스트)
